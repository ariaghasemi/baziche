# 🖧 استراتژی Build Server (VPS)

> وضعیت فاز ۱: **نیازی به VPS نیست.** بیلدها در فاز ۵ با GitHub Actions (رایگان) انجام می‌شوند.
> این سند برای روزی است که از سقف رایگان گیت‌هاب عبور کردی (Scale) — معماری `AgentManager` از قبل آماده است.

## چه زمانی VPS بخرم؟

وقتی یکی از این‌ها رخ داد:

- بیش از ~۳۰۰ بیلد در ماه داری (پایان سهمیه رایگان گیت‌هاب).
- بیلدها بیشتر از ۱۰ دقیقه در صف می‌مانند.
- به کنترل بیشتر (کش دائمی Gradle، منطقه خاص) نیاز داری.

## مشخصات پیشنهادی

| | حداقلی (شروع) | تولید (Production) |
|---|---|---|
| CPU | 4 vCPU | 8 vCPU |
| RAM | 8 GB | 16 GB |
| دیسک | 80 GB SSD | 160 GB SSD |
| سیستم‌عامل | Ubuntu 24.04 LTS | Ubuntu 24.04 LTS |
| موقعیت | اروپا (هلند/آلمان) | اروپا + (آینده: دومین نود) |

ظرفیت تقریبی هر نود حداقلی: ~۱۵–۲۵ بیلد همزمان-سری در ساعت (بسته به کش).

## چک‌لیست راه‌اندازی (اجرا در فاز Scale — فعلاً انجام نده)

```text
[ ] خرید VPS با مشخصات بالا
[ ] ساخت کلید SSH (ssh-keygen -t ed25519) و اتصال
[ ] Update سیستم + نصب Docker
[ ] نصب JDK 17 + Android SDK (cmdline-tools، platform-36، build-tools)
[ ] استقرار Build Agent (داکر Phase 5+) با توکن ایجنت
[ ] ثبت ایجنت در جدول agents (وضعیت online + heartbeat)
[ ] بیلد آزمایشی + بررسی ایزولاسیون و Cleanup
```
